# Artifacts

Write-ups documenting significant pieces of work on this project — what was done, why, decisions made, and problems hit along the way. This is history/context that isn't obvious from the code or git log alone.

## Convention

- One file per initiative: `YYYY-MM-DD-short-slug.md`
- Suggested sections: **Goal**, **What was done**, **Decisions & why**, **Issues encountered**, **Result / how to verify**
- Keep it a record of what happened, not living documentation — if something belongs in the README or code comments, put it there instead and just reference it here.
